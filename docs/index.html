SysMonitor.

PyQt6 打造的 Windows 系统监控面板 —— CPU / 内存 / 网络 / 多 GPU 实时监控，精确到每个进程。

下载最新版 GitHub 源码

Windows 10 / 11 · 单文件 exe（Nuitka 原生编译，约 26 MB）· MIT 开源

三种主题，跟随系统

实时跟随 Windows 深浅色与强调色，一键切换

功能一览

零驱动 · 全 GPU 覆盖 · 每进程溯源

🖥️

CPU 全维监控

总占用与每核心占用、历史曲线、LHM 温度（需 PawnIO 驱动）、EMI 硬件功耗、随睿频实时变化的当前频率。

🎮

多 GPU 自适应

每张卡独立卡片：使用率曲线、显存、温度 / 功耗 / 频率 / 编解码，标题实时显示 PCIe 链路（x8 4.0 @ x1 1.1）。

📊

每进程显存

任务管理器同源数据，按 CUDA luid 精确归卡；WSL2 的占用一眼识别（归属 vmwp.exe）。

🌐

每进程网络流量

实时列出占用带宽最高的进程；总上下行速率常驻显示。

🧠

内存明细

物理 / 交换占用、内存条频率、占用最高的进程排行，后台枚举不卡界面。

✨

Mica 云母材质

Windows 11 原生 DWM 背景材质，三态主题切换，窗口置顶，托盘常驻，分区刷新频率可调。

开始使用

下载单文件 exe 双击即用，无需安装。CPU 温度读取需管理员权限，启动时在加载界面询问是否启用（可跳过）。
